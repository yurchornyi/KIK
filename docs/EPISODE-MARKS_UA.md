# Пропуск заставки й «Наступна серія»

Працює на TV і на сайті, у профілях з перемикачем **«Пропуск реклами й заставок»** (Адмінпанель → Акаунти → Профілі; раніше перемикач називався «Пропуск реклами»). Для інших профілів сканер нічого не завантажує й не порівнює.

## Що бачить глядач

- **Логотип на старті серії** (Netflix тощо, до 15 с у перших 3 с) KIK пропускає сам, як уже пропускав логотипи студій Rezka Studio й ColdFilm.
- **Довша заставка:** поки вона йде, з'являється біла кнопка **«Пропустити заставку»** на місці «Пропустити рекламу». На TV її натискають OK, на сайті кліком або Enter.
- **Кінцеві титри:** справа внизу з'являється **«Наступна серія»**.
  - Якщо сканер знайшов початок титрів, кнопка рахує 10 с («Наступна серія через 8») і вмикає наступну серію сама, коли увімкнено «Наступна серія автоматично». На паузі відлік стоїть.
  - Якщо титри не знайдено, кнопка з'являється на останніх 5% серії без відліку: вгадане місце не має права обрізати останню сцену.
  - Щоб лишитися на титрах: на TV «Назад», на сайті «Дивитися титри».
- Серії без заставки (наприклад, нові «Сімпсони», де замість заставки ~4 с титру, різного в кожній серії) кнопки не отримують.

## Як знаходиться

| Частина | Файл |
|---|---|
| Пошук за звуком | `web/marks-detect.mjs` |
| Сканер на ПК | `web/scanner/scan.mjs` (поруч зі сканером реклами) |
| API й база | `web/episode-marks.mjs`, міграція `0016-episode-marks.sql` (`episode_marks`, `mark_scan_queue`) |
| Правила для плеєрів | `web/public/episode-marks.js`, на TV `PlaybackPolicy` + `EpisodeMarks.java` |

1. **Черга.** Плеєр профілю з перемикачем питає `GET /api/marks` для поточної серії й для наступної. Якщо серію ще не сканували, вона стає в чергу. Тож поки дивишся серію, сканер готує наступну.
2. **Сканер на ПК** раз на 5 хв бере до 5 серій. Посилання на відео він бере в KIK (`POST /api/marks/source`): HDRezka питає Cloudflare, ПК лише читає CDN. На кожну серію він бере звук перших 10 хв і останніх 7 хв у найменшій якості, кешує відбитки (`~/.kik-ad-scanner/marks`, до 400 серій) і порівнює з чотирма найближчими серіями сезону.
   - **Заставка** — те, що звучить однаково на початку щонайменше у двох інших серій. «Раніше в серіалі» збігається лише з однією серією, тож заставкою не стає.
   - **Титри** — останнє, що звучить однаково біля кінця хоча б з однією іншою серією (тема титрів, логотип студії в них). Остання сцена в різних серій не збігається.
   - Якщо CDN не віддав жодної сусідньої серії, результат не записується, і серія лишається в черзі (три спроби).
3. **Результат** (`POST /api/marks/report`) перевіряється так само, як у плеєрі: заставки від 3 до 180 с у першій третині серії (максимум 12 хв), титри в останніх 10 хв. Плеєр довіряє позначкам лише для того самого файлу, тобто тривалість має збігтися до 2 с. Якщо нічого не знайдено, серію сканують знову через 3 дні.

Перевірено 11.11.2026 на «Формулі 1: Ганяти, щоб виживати», сезон 8 («Українська Багатоголосе»): у всіх 8 серіях знайдено логотип Netflix (0:01–0:05) і початок титрів (за 30–107 с до кінця).

## Оновити сканер на ПК

Нова робота входить у той самий процес, що й сканер реклами. На ПК:

```sh
cd KIK && git pull && cd web && npm install --omit=dev
```

Потім перезапустіть сканер (той самий `KIK_SCANNER_TOKEN`). Без оновлення пропуск логотипа й заставки не працюватиме. «Наступна серія» тоді з'являтиметься на останніх 5% серії, без відліку.

Одну серію можна перевірити вручну (нічого не записує на сервер):

```sh
node --import ./register.mjs scan.mjs marks <посилання на сторінку серіалу> <сезон> <серія> <id озвучки>
```

## Перевірки

`npm test` у `web/` (`episode-marks.test.mjs`) перевіряє:
- синтетичний звук: логотип і заставку на різних хвилинах знайдено, а «раніше в серіалі» ні;
- титри;
- вибір сусідніх серій;
- правила кнопок;
- чергу лише для профілю з перемикачем;
- секрет сканера й перевірку звіту.

`scripts/PolicyCheck.java` перевіряє ті самі правила на TV.
