# Канали Android TV для TV Home

KIK публікує три канали головного екрана Android TV (`TvContract`) у такому порядку:

| `internal_provider_id` | Назва | Що в ньому |
|---|---|---|
| `tvhome:continue` | Продовжити перегляд | Почате й не додивлене, найновіше першим, з позицією й тривалістю. Фільм — від 1 хвилини; серіал, що перейшов на наступну серію, — одразу. |
| `tvhome:for_you` | Для вас | Той самий ряд «Рекомендовано для вас», що на головній KIK, з фільтром країн. |
| `tvhome:new_episodes` | Нові серії | Серіали, де остання переглянута серія додивлена, а наступна вже вийшла; далі — остання серія серіалів з «Мого списку», які ще не почато (відкриває сторінку серіалу). |

Код: `localization/java/kik/i18n/TvChannels.java`.

## Чий профіль

Канали належать профілю, у якому **останнім** відтворювалось відео: він зберігається в `kik_tv_channels`, коли у плеєрі стартує відео. Якщо стартує інший профіль, усі три канали перезаписуються його даними. Сам вибір профілю нічого не змінює. До першого відтворення береться профіль з найсвіжішою історією.

## Коли оновлюється

- старт відтворення в іншому профілі — усі три канали;
- закриття плеєра — «Продовжити перегляд»;
- `JobScheduler` раз на 4 години (з мережею) і запуск KIK, якщо минуло понад годину, — усі три.

ID каналів стабільні: канали оновлюються, а програми замінюються (старі видаляються, нові вставляються).

## Програми

- Назва українською (як у KIK), `searchable=1`, `weight` — вищий першим, тип фільм / серія / серіал.
- Постер — TMDB-бекдроп 16:9, 1280 px, через `POST /api/artwork/batch` web-сервера KIK. Кеш 30 днів, промахи — 3 дні. Для точного збігу потрібні оригінальна назва й рік; якщо їх немає в кеші, сторінка тайтлу читається один раз. Програма без 16:9-постера не публікується.
- `intent_uri` → `OpenTitleActivity` з `kik.link`, `kik.profile`, `kik.play`, `kik.season`, `kik.episode`. Відкриває саме цей тайтл; для «Продовжити» та «Нові серії» одразу запускає відтворення з позиції в історії. Профіль без пароля перемикається на профіль програми; профіль з паролем лишається поточним. Приймаються лише посилання на сторінки тайтлів каталогу.

## Старі канали RezkaTV

Канали Новинки, Смотрят, Горячие, История, Обновления сериалов видаляються при першій публікації, а старий менеджер каналів (`na7`) вимкнено в `scripts/simplify.py`, щоб він їх не відновив.

## Перевірка

```
adb logcat -s KIK.Channels
adb shell cmd jobscheduler run -f rezkatv.web.app.uk 1263094529
```

Перевірка з боку лаунчера (`adb logcat -s TvHome.ChannelFeed` → `rezkatv.web.app.uk: N programs`) потребує TV Home 2.47+.
